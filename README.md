# Text Buffer System in C

A menu-driven Text Buffer System developed using **C programming and a Doubly Linked List**. It allows users to perform basic text editing operations and manage text efficiently through a simple command-line interface.

## Features

- Insert text into the buffer
- Delete specific words or characters
- Find words in the text
- Replace words
- Undo and redo replace operations
- Display word frequency
- Convert text into Morse code
- Convert Morse code back into text
- Display the current text buffer

## Concepts Used

- C Programming
- Doubly Linked Lists
- Dynamic Memory Allocation
- Pointers and Structures
- String Handling
- Menu-Driven Programming

## How to Run

1. Download or clone this repository.
2. Open the project in Code::Blocks or any C compiler.
3. Compile and run the source file.
4. Use the menu displayed in the console to perform operations.

## Purpose

This project demonstrates how a Doubly Linked List can be used to build a basic text editor while implementing important data structures concepts such as insertion, deletion, traversal, and memory management.
